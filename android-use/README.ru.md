# Android Use 0.0.1 — плагин-помощник Mini Codex

**Android Use** дополняет [Mini Codex Android](https://github.com/kalabuxova1-hash/mini-codex-android) отдельным виртуальным экраном Android. Mini Codex управляет телефоном, а Android Use позволяет работать с интерфейсом приложений, не перехватывая основной экран пользователя.

**Возможности:** запуск приложений, нажатия, свайпы, кнопки навигации, снимки виртуального экрана, поиск элементов интерфейса, нажатие по тексту, ввод текста и пакетные действия. Контроллер проверяет принадлежность виртуального экрана и не использует физический экран 0 как запасной.

**Преимущества:** можно продолжать пользоваться телефоном во время работы помощника; после первоначальной настройки для работы не нужен включённый ПК; связь с агентом работает через личный защищённый HTTPS-сервер. Плагин необязателен и не заменяет Mini Codex.

**Установка только через Codex на ПК:** скачайте репозиторий и передайте Codex файл [INSTALL_WITH_CODEX.md](INSTALL_WITH_CODEX.md). Codex проверяет готовое устройство, устанавливает компоненты через разрешённый ADB и проверяет работу. **Root и Magisk не устанавливаем**, они должны быть подготовлены самим владельцем заранее. Также нужен Termux Python. Личный сервер и подключение плагина настраиваются отдельно.

**Версия:** 0.0.1. Проверено на конкретном Android 16 с root; совместимость с другими устройствами не гарантируется.

**Поддержать проект:** [добровольное пожертвование через Boosty](https://boosty.to/mini_codexandroid).
