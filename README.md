# Мини Codex — плагин для телефона

Управляйте собственным Android из ChatGPT: работайте с файлами, скачивайте и устанавливайте приложения, выполняйте команды. После настройки компьютер не требуется.

## Что нужно

- Android с **уже установленным root и Magisk**. Root пользователь устанавливает самостоятельно; прошивки, драйверы и инструменты разблокировки здесь не распространяются.
- Официальный [Termux](https://github.com/termux/termux-app/releases) с Python.
- Личное подключение плагина «Мини Codex» к вашему ChatGPT и отдельному закрытому серверу.

## Как подключить

1. Установите Termux, откройте его и выполните:

   ```sh
   pkg update && pkg install python
   ```

2. Подготовьте **свой** закрытый сервер и личный плагин по [инструкции подключения](docs/deploy-private-relay.md). Можно поручить эту настройку своему Codex — готовый запрос приведён в инструкции. У каждого пользователя собственные ключи и подключение.

3. Скачайте только `mini-codex-magisk-0.1.0.zip` из [выпуска](https://github.com/kalabuxova1-hash/mini-codex-android/releases/tag/v0.1.0). Это агент Mini Codex, **не установщик root**. Проверьте контрольную сумму из `SHA256SUMS`, установите ZIP в Magisk → Модули → Установить и перезагрузите телефон.

4. В Termux выполните:

   ```sh
   su -c /data/adb/modules/mini_codex/configure.sh
   ```

   Разрешите root. Введите адрес своего сервера, свой ключ агента и полное значение `Bearer <ваш Sites bypass>`, если оно требуется. Секреты вводятся скрыто. Перезагрузите телефон.

5. Установите и подключите **свой личный Site-плагин** в ChatGPT. Напишите: «Проверь статус моего телефона и доступ root». Затем проверьте работу при отключённом ПК.

**Готово:** дальше действия задаются в ChatGPT. Отдельные APK, исходники и средства прошивки скачивать на телефон не нужно. Агент необходим: плагин передаёт ему задания, а он исполняет их на Android. Без агента один плагин не даёт доступ к устройству.

## Важно знать

Текущий личный плагин автора не является общим сервером для чужих телефонов. Публичная инструкция помогает создать собственное подключение. Доступность мобильного плагина зависит от аккаунта ChatGPT и проверяется при подключении; установка ZIP не включает отсутствующие функции аккаунта.

Память и служебные записи агента ограничены **5 GiB**. Произвольные скачивания и запись файлов root-командами в этот бюджет не входят. Память хранит заметки между задачами, не обучает веса модели.

Чтобы остановить управление, отключите модуль Mini Codex в Magisk. При удалении модуля память и конфигурация сохраняются. Не передавайте ключи или доступ к личному плагину другим людям.

Проверенная конфигурация агента: Redmi Turbo 3, Android 16, Magisk, Termux. Новый публичный ZIP проверен тестами на компьютере и в mock-окружении; его не ставили поверх работающей личной установки. Другие устройства требуют проверки.
