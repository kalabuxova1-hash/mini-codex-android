# Установка на Android

[English](install-android.md) | Русский

Mini Codex запускает Python-агент на **вашем телефоне с root**. После установки компьютер не нужен. Агент отправляет авторизованные исходящие HTTPS-запросы в **ваш собственный приватный relay** и не открывает сетевой порт на телефоне. Подключение плагина этого relay к ChatGPT — отдельный шаг настройки аккаунта. Установка ZIP не выдаёт приложению ChatGPT разрешение Magisk и не подключает плагин автоматически.

## Перед установкой

1. Разблокируйте/root-ируйте собственный Android и установите Magisk. Сохраните способ восстановления своего устройства.
2. Установите официальный [Termux](https://github.com/termux/termux-app#installation). Используйте официальный выпуск; дополнения Termux должны быть из того же источника. Откройте Termux и выполните `pkg update`, затем `pkg install python`. Откройте приложение хотя бы один раз, чтобы появилась его приватная среда. Агент использует `/data/data/com.termux/files/usr/bin/python`; удаление Termux удаляет и эту среду.
3. Подготовьте отдельный **приватный** relay по [инструкции](deploy-private-relay.ru.md). Получите его базовый HTTPS URL, индивидуальный ключ агента и, если требуется, ключ Sites bypass. Не используйте URL другого владельца и не делитесь ключами. Доступ ChatGPT к relay также должен защищаться авторизацией аккаунта.

## Установка и настройка

1. Скачайте `mini-codex-magisk-0.1.0.zip` и проверьте SHA-256 по `SHA256SUMS` из релиза.
2. В Magisk выберите **Модули → Установить из хранилища**, укажите ZIP и перезагрузите телефон. Устанавливайте через приложение Magisk, не через recovery. Новая установка остаётся неактивной и не отправляет запросы relay, пока локальная настройка не завершится успешно.
3. В Termux выполните:

   ```sh
   su -c /data/adb/modules/mini_codex/configure.sh
   ```

   Подтвердите запрос root для Termux в Magisk, если он появится. Введите базовый HTTPS URL **своего** relay. Оба поля ключей скрывают ввод; оставьте необязательный ключ Sites пустым, если relay его не требует. Если Sites требует bypass-заголовок, введите полное значение `Bearer <ваш собственный bypass>`. Секреты записываются в `/data/adb/mini-codex/config.json` с правами `0600`; приватные папки имеют права `0700`. Секреты не передаются аргументами командной строки.

   Вместо ручного ввода можно локально импортировать личный файл конфигурации:

   ```sh
   su -c '/data/adb/modules/mini_codex/configure.sh --import /storage/emulated/0/Download/my-relay.json'
   ```

   Поля JSON: `relay_url`, `agent_token` и необязательное `sites_authorization`; ключ агента должен содержать не менее 40 символов без пробельных знаков. Используйте криптографически сгенерированный ключ из 64 шестнадцатеричных символов, как в инструкции relay. Импортируемый файл должен быть обычным файлом; пути с символическими ссылками отклоняются. После импорта удалите скачанный файл с ключами. Существующая конфигурация заменяется только после локального ввода `REPLACE`. Отмена импорта сохраняет старую конфигурацию и состояние.
4. Перезагрузите телефон, разблокируйте его один раз при шифровании хранилища и подключите **плагин своего приватного relay** к своему аккаунту ChatGPT. Сначала проверьте `phone_status`: ID root должен содержать `uid=0`. Проверьте запись/чтение временного файла перед использованием удалённых операций. Установка и подключение к ChatGPT — разные состояния.

## Что работает и что сохраняется

Magisk запускает `service.sh` модуля на позднем этапе загрузки. Неблокирующая блокировка агента предотвращает обработку одного состояния двумя процессами. Проверка HTTPS-сертификатов остаётся включённой; редиректы с ключами отклоняются. Неудачные и прерванные действия записываются и не выполняются повторно незаметно. Действие, уже выполняющееся при остановке агента, может завершиться; проверьте результат перед повторением.

Приватная базовая папка — `/data/adb/mini-codex`. Обновления сохраняют конфигурацию, память и журнал заданий. Общий объём памяти, журнала и логов ограничен 5 GiB: память резервирует 16 MiB для ограниченных журнала/логов. Диагностика запуска имеет общий лимит 64 KiB и перезаписывается при каждом запуске; обычные логи агента ротируются. Память хранит краткие сводки/скрипты и сжатые старые заметки, а не полные экспорты чатов, скриншоты или APK. Это сохраняемый контекст, не обучение модели и не автоматическое расширение разрешений Android. Root-инструменты могут менять файлы и приложения телефона по вашему запросу.

## Остановка, перезапуск и удаление

Для немедленного локального отзыва доступа:

```sh
su -c /data/adb/modules/mini_codex/stop.sh
```

Команда удаляет локальный маркер включения и завершает соответствующий процесс агента. Чтобы возобновить работу, повторно импортируйте собственную конфигурацию, подтвердите замену и перезагрузите телефон. Отключение/удаление модуля в Magisk также прекращает будущие опросы; при выводе устройства из эксплуатации отзовите ключ агента на relay.

Удаление модуля **сохраняет** `/data/adb/mini-codex`, чтобы повторная установка могла сохранить память и историю действий. Для окончательной очистки сначала остановите/удалите модуль, проверьте **точную** папку `/data/adb/mini-codex` в root-файловом менеджере, убедитесь, что это настоящая папка, а не ссылка, и удалите только её. При установке и удалении автоматическая очистка не выполняется.

## Проверки выпуска на компьютере

Из корня репозитория с установленным Python:

```sh
python -m unittest discover -s agent -p 'test_standalone.py'
python -m unittest discover -s tests -p 'installer_*.py'
python scripts/build_release.py
```

Сборка создаёт `dist/mini-codex-magisk-0.1.0.zip`, `dist/SHA256SUMS` и файлы агента для распространения в `dist/agent/`. Эти команды не обращаются к телефону и не включают конфигурацию владельца.
