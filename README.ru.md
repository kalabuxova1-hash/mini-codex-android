# Мини Codex для Android — управление телефоном через ChatGPT без ПК

[English](README.md) | Русский

**Мини Codex работает прямо на Android. Для его работы не нужен компьютер, ноутбук, USB, ADB на ПК или постоянно включённый домашний компьютер.**

Мини Codex — независимый проект с открытым исходным кодом. Агент на Python работает **на самом телефоне** через Termux и Magisk, сам получает подтверждённые владельцем задания с личного закрытого HTTPS-сервера и выполняет их в Android. Во время обычной работы компьютер может быть полностью выключен.

### Автономная работа без компьютера

```text
ChatGPT (на телефоне или другом поддерживаемом устройстве)
     ↕ личный плагин владельца
Личный закрытый HTTPS-сервер (работает в интернете)
     ↕ защищённые исходящие запросы
Сам Android: агент Мини Codex + Magisk + Termux
     ↓
Интерфейс, приложения, файлы и root-команды Android
```

- **Работа без ПК.** Команды выполняются непосредственно телефоном: управление файлами, загрузка файлов, установка одобренных APK, системные действия и root-команды. Не нужны Windows, Linux, macOS, scrcpy или ADB на компьютере.
- **Фоновый агент и автозапуск.** Magisk запускает агент после загрузки Android; агент сам забирает задания через интернет. ПК не должен быть включён или подключён. Фоновую работу могут ограничивать энергосбережение Android или необходимость первой разблокировки после перезагрузки.
- **Управление из ChatGPT.** Проверка заряда и состояния устройства, скриншоты, чтение элементов интерфейса, нажатия, свайпы, запуск приложений, работа с файлами.
- **Локальная память.** Краткие записи и архивы сохраняются на телефоне в пределах управляемого лимита 5 GiB. Это не обучение нейросети.
- **Личное подключение.** У каждого владельца собственный закрытый сервер, плагин и ключи. Общего публичного root-доступа проект не предоставляет.

**Важно:** «без компьютера» означает **для повседневной работы после настройки**, а не обязательную возможность получить root и подготовить любой Android без ПК. Для исполнения запросов всё ещё нужны интернет, работающий личный сервер, доступный плагин ChatGPT, Termux и root. Агент не является полностью офлайн-ИИ: он выполняет запросы через ChatGPT. Он не обходит защищённый экран блокировки. Скрытый виртуальный экран пока не заявляется как проверенная функция публичного релиза.

**Проверено:** личная конфигурация использовалась на Redmi Turbo 3 / Android 16 с root. Публичный ZIP v0.1.0 проверен тестами на хосте и в mock-окружении, но не устанавливался поверх рабочей личной версии. Остальные устройства требуют отдельной проверки.

Подробнее — [частые вопросы о работе без компьютера](docs/pc-free-android.ru.md).

## Инструкция по установке

## Что нужно

- Android с **уже установленным root и Magisk**. Root пользователь устанавливает самостоятельно; прошивки, драйверы и инструменты разблокировки здесь не распространяются.
- Официальный [Termux](https://github.com/termux/termux-app/releases) с Python.
- Личное подключение плагина «Мини Codex» к вашему ChatGPT и отдельному закрытому серверу.

## Как подключить

1. Установите Termux, откройте его и выполните:

   ```sh
   pkg update && pkg install python
   ```

2. Подготовьте **свой** закрытый сервер и личный плагин по [инструкции подключения](docs/deploy-private-relay.ru.md). Можно поручить эту настройку своему Codex — готовый запрос приведён в инструкции. У каждого пользователя собственные ключи и подключение.

3. Скачайте только `mini-codex-magisk-0.1.0.zip` из [выпуска](https://github.com/kalabuxova1-hash/mini-codex-android/releases/tag/v0.1.0). Это агент Mini Codex, **не установщик root**. Проверьте контрольную сумму из `SHA256SUMS`, установите ZIP в Magisk → Модули → Установить и перезагрузите телефон.

4. В Termux выполните:

   ```sh
   su -c /data/adb/modules/mini_codex/configure.sh
   ```

   Разрешите root. Введите адрес своего сервера, свой ключ агента и полное значение `Bearer <ваш Sites bypass>`, если оно требуется. Секреты вводятся скрыто. Перезагрузите телефон.

5. Установите и подключите **свой личный Site-плагин** в ChatGPT. Напишите: «Проверь статус моего телефона и доступ root». Затем проверьте работу при отключённом ПК.

**Готово:** дальше действия задаются в ChatGPT. Отдельные APK, исходники и средства прошивки скачивать на телефон не нужно. Агент необходим: плагин передаёт ему задания, а он исполняет их на Android. Без агента один плагин не даёт доступ к устройству.

## Важно знать

Текущий личный плагин автора не является общим сервером для чужих телефонов. Публичная инструкция помогает создать собственное подключение. Доступность мобильного плагина зависит от аккаунта ChatGPT и проверяется при подключении; установка ZIP не включает отсутствующие функции аккаунта.

Поддержать разработку Mini Codex можно добровольным донатом на [Boosty](https://boosty.to/mini_codexandroid). Поддержка помогает развивать проект, проверять совместимость, исправлять ошибки и улучшать документацию. Исходники и публичные выпуски остаются бесплатными по лицензии MIT.

Память и служебные записи агента ограничены **5 GiB**. Произвольные скачивания и запись файлов root-командами в этот бюджет не входят. Память хранит заметки между задачами, не обучает веса модели.

Чтобы остановить управление, отключите модуль Mini Codex в Magisk. При удалении модуля память и конфигурация сохраняются. Не передавайте ключи или доступ к личному плагину другим людям.

Проверенная конфигурация агента: Redmi Turbo 3, Android 16, Magisk, Termux. Новый публичный ZIP проверен тестами на компьютере и в mock-окружении; его не ставили поверх работающей личной установки. Другие устройства требуют проверки.
